## Two load-bearing bugs caught

1. The originally archived probe omitted the precharge accumulation of \`tau\`, causing Eq. (25)'s third-step compensation to use a zero incoming trace instead of \(\kappa_L\). Already documented in [ERRATUM.md](ERRATUM.md).
2. **New:** the array \`stationary\` already contained zero-based indices (because of a trailing \`-1\`), but the old \`donor=np.r_[moving_coordinates,stationary]-1\` subtracted 1 a SECOND time from stationary indices. Consequently the active compensators differed from the initialized compensators, and an apparent private gate appeared outside the intended donor set. The repaired line is:
   \`donor=np.r_[A+np.arange(m)+t,B+np.arange(m)+t,stationary]\`.
   The probe now verifies at each time that gate arrays for antipodal histories are identical outside the intended donor coordinates.

The second indexing repair affects values only at about \(10^{-14}\) relative scale in these particular tested M/L/H query scores, but it repairs geometric legality. It is NOT safe to leave a known indexing error in a geometry-sensitive theorem.
