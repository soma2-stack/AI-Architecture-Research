## Selection before the long proof

C1 wins because an existing *finite-amplitude* comparison already tolerates
every simultaneous idle donor value. It can certify many coordinates at
once. The old proof selected just one coordinate and paid sqrt(K) duration.
We instead deliberately exclude sparse boundary controls using a public,
continuous clipped full-spark frame. This is an error-correcting section of
the donor cube, not an assumption of a better write matrix.

The new load-bearing work is the frame/code theorem and a complete row-norm
comparison. In particular, charging the front, tail, and mask separately to
K scalar tests would reintroduce artificial sqrt(K) losses. The private
response must be bounded as one row vector on the orthonormal probe space.
No donor epochs are counted as dimensions. All local donor traces will
still be matched exactly. The selected route changes neither the frozen
RNN nor the legal-query contract.

to the project phase diagram.
