# Failed routes and exact limitations

No accepted theorem is changed. Failures below are scoped to the attempted extension, not all recurrent histories.

| Route | Status | First failed or missing statement |
|---|---|---|
| E large donor epochs times one persistent survivor word | CLOSED for this extension by a new static code | E separate contributions do not give E output rows: the sum is ONE private row vector V. COMPLETE robust D is bounded by mp+3q_P, independent of E. |
| Label an unchanged survivor block as C cohorts | FAILED | Equal whole gate words give exactly equal V rows. Renaming does not change the map. |
| Identify cohorts because their last gate is equal | FAILED | V_i-V_j retains earlier differences. The independent toy case returns a nonzero difference despite identical final gates. |
| Count two instantaneous gate values as two whole-word classes | FAILED | Different switching schedules are different words. C in the theorem requires a fixed public partition with equal entire schedules. |

| Multiply the one-probe signal into superlinear dimension | FAILED | Any fixed probe gives at most r output coordinates; the earlier strong pair controls one direction only. |

| Promote the new static code to an online O(n) encoder | UNPROVED | Final row codes do not themselves close under online updates. The exact counted bank is larger. |
| Close every growing-cohort corridor | OPEN | Need a finite-error width theorem for the reachable Vcal(g) matrix. The new counts can be superlinear when C grows, or m>>sqrt(n) in the stationary block. |
| Derive an energy lower from the corridor cost upper | INVALID | R<=2sqrt(m(T+2)+1) cannot be reversed. All new obstructions concern continuous coordinates, not a universal energy threshold. |

The direct profile attempt is one REAL joint legal ball: donor prefix g_i,t=.995+.001 theta_i,e, followed by exact trace corrections. Every combination is admissible, the endpoint is common, and energy is bounded. When its raw ball dimension exceeds the applicable code, Borsuk-Ulam proves a boundary antipodal collision. This is stronger than failing a local optimization, but only within the specified subclass.

No universal failure of multi-cohort renewal is proved. No new global impossibility exponent is claimed.
