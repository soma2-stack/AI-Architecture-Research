# Multi-donor joint-section study — frozen scope

Codex, 2026-10-03. This is new work. Accepted historical folders and independent reviews are read-only.

## Question

Can many donor epochs and survivor cohorts produce one jointly robust continuous section with D=omega(n), mT=o(n^(3/2)), epsilon=.001, and the unchanged fixed-feature/legal-query contract? Race a scoped compression proof against a construction. Do not infer dimension from epochs, variables, tangent rank, or separately visible axes.

## Analytical protocol

1. Use the accepted exact full renewal, including bath, front, reset, and every Householder insertion.
2. Derive epoch propagators and exact trace corrections for arbitrary donor prefixes.
3. Audit survivor row equivalence: identical whole gate words versus identical terminal gates.
4. Bound the public front in the actual all-legal-query metric. Try a complete static code for fixed survivor gate classes and a separate code for stationary-compensator input parameters.
5. Derive necessary exponent constraints. If no joint superlinear construction follows, isolate the unresolved cohort matrix; do not close the entire corridor.

## Small numerical protocol (fixed before execution)

- One fresh Python process, every numerical library pool limited to one, no workers, no PyTorch, no CUDA, no GPU calls.
- Stop above 8 process threads, any child process, or 160 MiB working set. Record observed resources. This job launches numerical processes sequentially.
- Independent implementation, no import of previous research kernels.
- n=65536, m=6, T=32, tail=8; tiny gate modulation, multiple epochs and two survivor classes. This is an algebra test, not an official asymptotic robust candidate.
- Test epoch composition, complete row renewal, exact trace equality, analytic differentiated correction versus central differences, equal-word row collapse, unequal-word counterexample, off-cycle annihilation, front bounds, reset, and actual raw-history energy.
- A small explicit co-moving query frame tests the exact overlap and legal sign-query inequalities. No numerical rank is called a robust dimension.
- Nine independent donor/epoch derivatives in the streamed toy case provide a local transfer spectrum; this is explicitly not a finite-radius robust count.
- Scalar constants at 192 and 256 bits. Numerical arithmetic cross-checks are not interval certificates or theorem proofs.

## Stopping criterion

Save an internally checked theorem or precisely scoped obstruction and the first unresolved finite-radius statement. Stop this stage. Do not launch architecture work or a new search campaign.
