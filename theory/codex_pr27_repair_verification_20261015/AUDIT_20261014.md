## Independent verification of the imported mathematics

### Model, transport, and fixed-feature scope

Write `a=1-1/n`, `lambda=1/(100n)`, `k=floor(n/2)`, `l=n-k`, `d=floor(n/4)`, and `gamma=1/(1-1/sqrt(k))`. For `U=I-gamma ww^T`, `w=e0-1/sqrt(k)`, we have `U^2=I`, `Ue0=u`, `Uu=e0`, and `Pu=u`. Thus `Oe0=e0`, and by orthogonality row 0 also decouples. The memory operator is the finite cycle conjugate `O=UPU`.

For `x0=0`, direct expansion gives exactly

```
J(x) = gamma x_(d-1)/sqrt(k) - gamma^2 sum_(j>=1) x_j/k,
(Ox)_1 = J(x) + gamma sum_(j>=1) x_j/sqrt(k),
(Ox)_j = x_(j-1) + J(x),       2<=j<=d-1,
(Ox)_j = x_j + J(x),          d<=j<k.
```

The local skeleton is a partial shift: `1 -> 2 -> ... -> d-1 -> termination`; off-cycle rows map to themselves. It is not a wrapped cycle. Row `d-1` re-enters other rows through the global bus, not the own path. The predecessor map on ordinary memory rows is injective, and adding the disjoint source self-maps preserves injectivity.

With `H=R-R0`, every component of `Hh` is at most `rho=delta sqrt(n)`, since `|h_i|<1`. This includes source-to-memory, row-0-to-memory, and every dense residual effect; no residual support restriction is assumed. `||R||<=1` follows either from the exact contract `||R||=a`, or already from `a+delta<1` in the stated range.

For PR #28, the parameter group is **exactly** `{u f_s^T:u0=0}`, with dimension `n-1`, where `f_s=1_l/sqrt(l)`. It includes source-row directions and excludes the direction injecting into row 0. The proof does not control full R/W/b gradients. This group and the recurrent-group/loss ratio `1/n` must remain explicit.

### Lemma 2.1: bath identity — PROVED

Use the actual history's J to define `F_t(y)=tanh(.05+aJ_t+ay)` and `s1=tanh(.05)`, `s_(t+1)=F_t(s_t)`. For `M_t=Sum'_t-(k-1)s_t`,


This identity remains exact with dense R: it is an algebraic identity for a virtual process driven by the actual J. It does not say that an actual never-driven row equals the virtual bath. Its absolute remainder satisfies `|E_t|<=3a/(sqrt(k)-1)<=3gamma/sqrt(k)`.

### Lemma 2.2: chains and dense forcing — PROVED

Trace each undriven ordinary row backwards until a drive, the front, or time 1. There is one predecessor and at most one successor. Starts at a specified time consist of at most m drives and one front step. Therefore there are at most `m+1` noninitial chains of each age at a fixed observation time. Interrupted chains restart; they do not create additional successors. At time 1 an undriven row has exactly `tanh(.05)`, also for actual R, because `Hh0=0`.

Compare a chain to the composition of the same `F_t`, starting at its actual start value and using the same actual J at every step. If its scalar error is e, tanh's Lipschitz bound gives

```
e_(r+1) <= a e_r + rho,    e_0=0,
e_A <= rho (1-a^A)/(1-a) <= n rho <= 4e-8/sqrt(n).
```

This is an independent, stronger completion of the written `A rho` comparison. It holds at every horizon. There is no comparison to an autonomous R0 trajectory with a different J, and hence no missing uncontrolled mean-field feedback.

The author's weaker comparison is enough for Theorem 4: there `T<=2.5e-5 n^(3/2)<n^(3/2)`, so `T rho<=4e-8`. The unqualified all-time statement in Lemma 2.4 nevertheless needs the geometric sum above if it is retained.

Let `s_u,s_(u+1)>=s0=1/40`, and set `B=atanh(s_(u+1))`, so `F_u(s_u)=tanh(B)`. For a reference chain above the bath with gap d,


Both trajectories use the same F. The inequalities do not require a stationary bath or constant beta. Above/below order is preserved by monotonicity.

Below the bath, with `d=s-y>=0`,

Whenever `a d>=s0/2`, the integral contains `[B-s0/2,B]`, which is a positive right shift of `[s0/2,s0]`. Since `tanh(z)>=z-z^3/3`, its decrement is at least

Thus the conservative lifetime `Lambda=450000` is valid even under adversarial bath oscillations. This is a gap-to-bath statement; it is not a claim that the individual state y itself is monotone.

## Exact auxiliary errors and counterexamples

### Lemma 1.2: incoming bus credit defeats the total-hole bound

The norm inequality `||B_t v||<=||B_(t-1)v||+|c_t|` is valid. The path sum bounds the **own-injection component** on a local cycle path; it does not bound the total credit carried by that row.

Take a neutral off-cycle hole j>=d, and the unit probe `v=e_(d-1)`. Maintain `h_t(j)=0` by the legal input `x_t(j)=-.05-(R0 h_(t-1))_j`; all other inputs are zero. With h0=0, c1=0 and B1=0. Then

```
B2 = c2 g2(d-1) e_(d-1),     c2=tanh(.05)/sigma>0,
B3(j) = a [gamma/sqrt(k)-gamma^2/k] c2 g2(d-1)>0.
```

Here the hole gate is 1 and `gamma/sqrt(k)-gamma^2/k>0` for k>4. Its own path visits only j, so `v_path=0` and the proposed total-credit upper bound is **zero**. The incoming credit is exactly the omitted bus delivery.

The independent legal reference-history reproduction at n=128, T=3, m=1 gives total hole credit `0.12124873254040437`, with maximum raw input `.05`, against claimed upper bound 0. The same symbolic positive bus coefficient exists in the theorem-scale reference model; this is not a small-n cancellation artifact. In the actual model `R_(j,d-1)=a O_(j,d-1)+H_(j,d-1)` remains positive at n>=1e8 since delta is far smaller than the positive reference coefficient. The paper's reference-model path bound is already refuted without needing this extension.

For a cycle's own part, a unit probe and distinct path positions do give the Cauchy–Schwarz bound `cmax sqrt(L)`. Broadcasting that content adds a `1/sqrt(k)` factor, so an order-one **broadcast per-row** amplitude from that own part requires L=Omega(n). A concentrated one-step probe alone does **not** contradict this broadcast scaling. Any restriction norm on an off-cycle repeated path must count repetitions, or instead use its correct geometric-sum bound. PR #28 handles these off-cycle sums separately.

### Lemma 1.3: order and destruction

For the stated post-gate credit recurrence `B_t=G_t a O B_(t-1)+injection`, setting `btilde=UB` gives

```
btilde_t = a (U G_t U) P btilde_(t-1)+injection.
```

The paper writes `a P(U G U)`. These factors do not commute; the independent matrix fixture finds commutator norm `0.428030228539...`. A suitably reindexed pre-gate variable could have the latter transport, but the paper does not define one there.
