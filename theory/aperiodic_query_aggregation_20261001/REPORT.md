## Result

### Strongest new theorem

For a fixed number b of arbitrary non-scalar memory-gate events at declared
public times, with arbitrary scalar memory gates between them, every horizon
admits a counted continuous encoder with

    [(b+1)d+l](2n+1)+2b k^2+b(2n+1)+1 = O_b(n^2)

credit/buffer coordinates, plus n if current h must be stored. It retains
shared moments and all history-dependent transport matrices. Source gates
are arbitrary. Future query gates are unrestricted by the past restriction.
The accepted quadratic section lies in this class, giving conditional
Theta_(c,b)(n^2). This genuinely permits aperiodic gate events, but does
not cover arbitrary event counts or freely detected history-dependent times.

### Strongest new obstruction

The SAME accepted family has an analytic, admissible, exact h_T=0 history
with one non-scalar memory pulse. Mean-scalar replacement of that pulse's
propagator loses, at c=1,

    actual permitted normalized query error >0.0012897776 >0.001,

even when its new injection is retained exactly. The construction uses all
real coupled R_mem,source injections; no columns or adjoints are privileged.
Its block-reference visible old-credit gain exceeds n/(40c), on directions
generated by permitted query differences. The actual dense error is transferred
with a uniform perturbation bound, not inferred from reference rank alone.

Thus query normalization cannot generally replace the old-credit multiplier
by a width-independent norm. A successful upper proof must exploit correlation
and sharing, not simply claim that the old coherent component is invisible.
