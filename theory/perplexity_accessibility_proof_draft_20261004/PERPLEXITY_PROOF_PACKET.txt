ARBITRARY-WIDTH ACCESSIBILITY OF THE TANH PARAMETER-SENSITIVITY LIFT
Critical proof text for direct review
Source: PROOF.md at commit 0cbe1a8

This is a mathematical proof draft supported by exact symbolic checks. It is not formally verified and has not received independent expert review. No numerical width sweep is used in the argument below.

==================================================
1. FORMAL THEOREM STATEMENT
==================================================

Theorem (universal over the fixed matrices satisfying the hypotheses): For every integer n >= 2, for every fixed pair of matrices R,W in R^(n by n) such that R is invertible, W is invertible, and every entry of A=R^(-1) is nonzero, for every fixed bias b in R^n, for every fixed initial augmented state (h_0,S_0) in R^n times R^(n by P_n), and for every nonempty open input set U contained in R^n, there exists a finite input history (u_1,...,u_T) in U^T whose endpoint map from the input history to the augmented state (h_T,S_T) has Jacobian rank d_n. One sufficient horizon is T=4d_n. The bound is conservative and does not prove the counting-minimum horizon P_n+1.

Here all entries of theta=(R,W,b) are independently differentiated, while theta remains fixed during the trajectory. The full sensitivity has P_n columns, one for each scalar parameter.

P_n = 2n^2 + n

d_n = n + nP_n
    = 2n^3 + n^2 + n.

Thus the theorem is universal over every fixed R,W satisfying the displayed hypotheses, not merely existential for one chosen family. The explicit rational family in Section 11 shows that the hypotheses have examples at every width. The statement for arbitrary S_0 is a statement about the augmented recurrence initialized at that point; the usual derivative experiment with a parameter-independent initial hidden state uses S_0=0.

==================================================
2. AUGMENTED SYSTEM AND EXACT SENSITIVITY RECURSION
==================================================

At each step, u is an n-dimensional continuous input and

q = R h + W u + b,
h' = tanh(q),
G = diag(sech^2(q)).

For a parameter perturbation delta=(deltaR,deltaW,deltab), let S delta denote the directional derivative of h with respect to theta in direction delta. Differentiating q and then tanh gives the exact recurrence

S' delta = G ( R S delta + deltaR h + deltaW u + deltab ).

No parameter update occurs. This is the derivative of the same frozen-parameter computation for every sensitivity method.

In separate parameter blocks, write S_R, S_W, S_b for derivatives with respect to R, W and b. With the R entries grouped by input/state column, these obey

S_R' = G R S_R + G [ h_1 I  h_2 I  ...  h_n I ],
S_W' = G R S_W + G [ u_1 I  u_2 I  ...  u_n I ],
S_b' = G R S_b + G I.

The source terms are the actual derivatives of the affine input q with respect to those parameters; they are not independently selectable sources.

For a state variation (v,K), where v is the perturbation in h and K delta is the perturbation in S delta, with theta and u held fixed, the augmented-state differential is

delta h' = G R v,

delta(S' delta) = G R (K delta) + G (deltaR v)
 + diag(tanh''(q) elementwise-multiplied by Rv)
   ( R S delta + deltaR h + deltaW u + deltab ).

The last term is the second-derivative term from differentiating G with respect to the changed hidden state. It must be retained in pullback calculations.

Ordering hidden-state coordinates before sensitivity coordinates, the Jacobian D_z f_u is block triangular. Its diagonal blocks are G R for h and the P_n-column lift of G R for S. Since every tanh derivative is strictly positive and R is invertible,

det(D_z f_u) = (det(GR))^(P_n+1) != 0.

Consequently each fixed-input augmented step is a local diffeomorphism everywhere. In fact it is a diffeomorphism onto the open image (-1,1)^n times R^(nP_n), with inverse obtained first from h=R^(-1)(atanh(h')-Wu-b), then from the affine equation for S. It is not a global diffeomorphism from R^(d_n) onto R^(d_n). The proof below uses the nonsingular one-step differential, not a false global-onto assumption.

For any fixed admissible parameter point with W=W_0 invertible, make the constant coordinate change u_new=W_0 u and W_new=W W_0^(-1). This preserves endpoint rank. W_0 is held constant under differentiation, so all W_new entries remain parameter directions. It is therefore enough to derive the pullback formulas at W=I. Put A=R^(-1), a_i=A e_i. The hypotheses give A_ij != 0 for every i,j.

For a vector field V on the augmented state, define the fixed-control pullback

f_u^* V(z) = (D_z f_u(z))^(-1) V(f_u(z)).

Let M_k be the local smooth module generated by control-variation fields pulled back along forward prefixes of length at most k. Coefficients may be smooth functions of z. Pullback maps M_k into M_(k+1). These are pointwise spans of vector fields, not yet ranks of a single short endpoint map; Section 9 proves the needed single-history statement.

Coefficient-extraction lemma. Suppose a control-dependent field has the form V(u,z)=sum_a phi_a(u,z) V_a(z). If the scalar functions phi_a(.,z_0) are linearly independent on an open set of controls, there are finitely many fixed controls u_1,...,u_s for which the evaluation matrix [phi_a(u_r,z)] is invertible at z_0 and remains invertible in a neighborhood. Solving that finite linear system expresses each V_a as a smooth local linear combination of V(u_1,.),...,V(u_s,.). Therefore every coefficient field V_a belongs to the same local module. This is finite-dimensional linear algebra; it does not substitute a state-dependent feedback law into a fixed-control derivative.

==================================================
3. CONTROL VARIATION / BASE GENERATORS
==================================================

For input coordinate j define the control-variation field

Y_j(z) = (D_z f_u(z))^(-1) partial_(u_j) f_u(z).

The hidden-state component of partial_(u_j) f_u is G W e_j. Its sensitivity component in parameter direction delta is

G deltaW e_j + diag(tanh''(q) elementwise-multiplied by W e_j)
 (R S delta + deltaR h + deltaW u + deltab).

Solve D_z f_u (v,K)=partial_(u_j)f_u. The hidden equation gives v=R^(-1) W e_j. In the sensitivity equation, the second-derivative terms cancel because Rv=W e_j. The remaining equation gives

K delta = R^(-1) (deltaW e_j - deltaR R^(-1) W e_j).

At the normalized coordinate W=I, this is

Y_j = ( a_j, -A deltaR a_j + A deltaW e_j ).

Here A=R^(-1), a_j=Ae_j. The sensitivity component is a linear map of the parameter direction delta. There is no bias component. The result is independent of u,h,S: the terms depending on q and S cancel in the inverse-differential calculation. This is the parameter-jet lift of the base hidden-state control direction R^(-1)W e_j.

==================================================
4. FIRST PULLBACK AND COEFFICIENT EXTRACTION
==================================================

Set c_i=cosh^2(q_i) and g_i=sinh(2q_i). The actual first-pullback identity is

f_u^*Y_j = sum_i c_i V_ij
         + sum_i A_ij g_i D_i
         + sum_(i,k) A_ij u_k g_i U_ik,

with fields

U_ik = (0, a_i deltaW_ik),

V_ij = ( a_i A_ij,
         -A deltaR a_i A_ij
         -a_i (A deltaR a_j)_i
         +a_i (A deltaW e_j)_i ),

D_i = (0, a_i [ deltaR h + deltab + R S delta ]_i).

Each field's second entry is a map acting on an arbitrary parameter direction delta. The D_i term contains the true coupled parameter injection and cannot be replaced by a freely chosen source.

The coefficient functions c_i, g_i and u_k g_i are linearly independent on every nonempty open control set. To see this, hold z fixed and use q=Rh+u+b, so each q_i differs from u_i by a fixed shift. Expand

c_i = (exp(2q_i)+2+exp(-2q_i))/4,
g_i = (exp(2q_i)-exp(-2q_i))/2.

Consider any linear combination of all c_i,g_i,u_k g_i that vanishes on an open set. Exponential polynomials are analytic, so it vanishes identically. For frequency vector +2e_i, its coefficient is an affine polynomial in u whose linear terms are exactly the coefficients of u_k g_i. Their vanishing forces every such coefficient to zero. The frequency vector -2e_i gives the opposite signs for g_i; combining the two frequency equations forces the coefficients of c_i and g_i to zero. Different i have distinct frequency vectors. The fixed shifts in q multiply frequency coefficients by nonzero constants and do not alter independence. Constant terms in c_i cannot cancel these distinct nonzero frequencies.

By the coefficient-extraction lemma in Section 2, every U_ik, V_ij and D_i belongs to M_1. The actual differential identity that verifies the pullback, including the necessary second derivative, is: for any proposed (v,K),

delta h' = GRv,
delta(S' delta) = GRK delta + G deltaR v
 + diag(tanh''(q) elementwise-multiplied by Rv)
   (RS delta+deltaR h+deltaW u+deltab).

Substituting the displayed fields in the first-pullback identity gives Y_j at the next state.

==================================================
5. FULL W-SENSITIVITY DIRECTIONS
==================================================

For a pure vertical field (0,K), the inverse state differential has zero hidden component and acts on each sensitivity column by (GR)^(-1)=A G^(-1). Thus

f_u^*(0,K) = (0, A G^(-1) K(f_u(z))).

Apply this to the actual field U_ik from Section 4. Since G^(-1)=diag(c_1,...,c_n),

f_u^* U_ik = sum_l c_l (0, a_l A_li deltaW_ik).

The c_l are independent coefficient functions and A_li is nonzero. Coefficient extraction therefore yields every constant field

(0, a_l deltaW_ik)

for all l,i,k. For fixed l these n^2 deltaW_ik directions span an n^2-dimensional output-parameter block; varying l gives n independent output vectors a_l, which form a basis because A is invertible. This produces n^3 independent W-sensitivity coordinates in M_2.

The deltaW u term was part of the original sensitivity source and produced the u_k g_i U_ik term in the first pullback. The proof propagates that coupled source through the actual state Jacobian. It never assumes the parameter columns can be selected independently during a trajectory.

==================================================
6. FULL R-SENSITIVITY DIRECTIONS AND HIDDEN DIRECTIONS
==================================================

Subtract from Y_j the pure W vertical component, which is available from Section 5. This gives

Z_j = (a_j, -A deltaR a_j) in M_2.

Subtract A_ij Z_i and the pure W component of V_ij. The remainder is

H_ij = (0, -a_i (A deltaR a_j)_i) in M_2.

Define the scalar covectors

C_ij = (A deltaR A)_ij.

Because A is invertible, the linear map from an arbitrary n by n parameter perturbation deltaR to the n by n matrix A deltaR A is invertible; its inverse maps C to A^(-1) C A^(-1). Therefore the C_ij form a basis of the n^2-dimensional dual space for R parameters.

Since H_ij=(0,-a_i C_ij), pull back once more:

f_u^* H_ij = -sum_l c_l (0, a_l A_li C_ij).

All A_li are nonzero, so coefficient extraction gives every (0,a_l C_ij). Vary l across the basis a_l and i,j across the basis C_ij. This yields all n^3 R-sensitivity coordinates in M_3.

Finally, subtract the complete R and W vertical components from Y_j. Its remaining field is (a_j,0). The a_j form a basis of hidden-state space, so these are all n pure hidden directions in M_3. This argument fills the parameter-sensitivity directions as well as the hidden-state directions; it does not follow merely from propagation matrices spanning the hidden-state matrix algebra.

==================================================
7. BIAS-SENSITIVITY CONSTRUCTION
==================================================

This construction uses the actual bias injection in the exact sensitivity recursion. Let S_b be the n by n derivative block for b, and define

Q = I + R S_b.

From S_b'=G(R S_b+I), it follows exactly that

Q' = I + R G Q.

The bias projection of the field D_i from Section 4 is

(0, a_i e_i^T Q).

For a vertical field, pullback multiplies its output side by A G^(-1). Evaluating D_i at the next state therefore gives the bias projection of its pullback:

K_i(G) = A G^(-1) a_i e_i^T ( I + R G Q ).

Write gamma_l=G_ll, so G=diag(gamma_1,...,gamma_n) with 0<gamma_l<=1. Expanding the expression using A=R^(-1) gives

K_i(G) = sum_l gamma_l^(-1) a_l A_li e_i^T
        + sum_(l,k) (gamma_k/gamma_l)
             a_l A_li R_ik e_k^T Q.

Why the R/W pieces can be subtracted. The full R and W vertical bases have already been obtained in Section 6. The R/W projections of f_u^*D_i are smooth vertical fields, so they are linear combinations, with smooth local coefficients, of those complete bases and can be subtracted. Vertical pullback is blockwise in parameter columns, so projecting onto the bias columns commutes with vertical pullback. The remaining bias field is precisely K_i(G). This subtraction does not change the bias component.

Why Q need not be invertible. Q occurs only as a coefficient in the second sum. No step solves for Q, divides by Q, or assumes it has full rank. The first sum has constant coefficients a_l A_li e_i^T independent of Q.

Why S_b need not be invertible. S_b is used only to define Q=I+R S_b and the update equation. No inverse of S_b is taken; no rank assumption on S_b is made.

Coefficient separation. The first-sum monomials gamma_l^(-1) are distinct Laurent monomials. In the second sum the monomials are gamma_k/gamma_l. When k=l these are the constant monomial 1; when k!=l they have exponent vector with +1 in coordinate k and -1 in coordinate l. None equals a monomial gamma_r^(-1), whose exponent vector has only -1 at coordinate r. Some ratio terms may coincide after collection, but they remain in the ratio class and do not collide with any inverse-gamma term. Distinct Laurent monomials are linearly independent on every nonempty open box of positive gamma values.

Such an open gamma box is available from inputs. At any fixed state, q=Rh+u+b because W=I. The input set is open, so q ranges over an open set. Choose a point with every q_i nonzero. The coordinate map q_i -> gamma_i=sech^2(q_i) has derivative -2 sech^2(q_i)tanh(q_i), which is nonzero there. The inverse function theorem gives an open box of attainable gamma values locally.

Apply coefficient extraction to K_i(G). It isolates each inverse-gamma coefficient a_l A_li e_i^T. Since A_li!=0, divide by that scalar to obtain every constant pure-bias field

(0, a_l e_i^T)

for every l and i. The a_l form a basis of output space, and e_i^T indexes the n bias-parameter columns. Hence these are all n^2 independent bias-sensitivity directions in M_3. This remains true even when Q or S_b is singular.

The identity matrix in Q'=I+RGQ is essential: it creates the constant first-sum term. Removing that injection would invalidate this construction.

==================================================
8. FULL DIRECT-SUM / SPANNING RESULT
==================================================

At every augmented state z, the fields generated by forward control pullbacks of prefix length at most 3 contain:

n hidden-state directions (a_j,0),
n^3 R-sensitivity directions (0,a_l C_ij),
n^3 W-sensitivity directions (0,a_l deltaW_ik),
n^2 bias-sensitivity directions (0,a_l e_i^T).

The a_l form a basis of R^n. The C_ij form a basis of the R-parameter dual. The W and b parameter blocks are separately indexed standard parameter coordinates. These four blocks occupy disjoint parameter columns, and hidden directions occupy the horizontal component. Their sum is therefore direct and has dimension

n + n^3 + n^3 + n^2
= n + nP_n
= 2n^3 + n^2 + n
= d_n.

Thus the local smooth module M_3 spans the entire augmented tangent space at every state. The prefix-length bound for this span is 3. This statement by itself is a span of pullback fields; the next section proves it yields one actual endpoint Jacobian.

==================================================
9. SINGLE-HISTORY RANK-INCREMENT LEMMA
==================================================

Lemma. Let a smooth discrete-time control system have state dimension d, nonsingular state differential for every admissible fixed-input transition, and control-variation pullback fields whose forward-prefix module of length at most L spans the full tangent space at every state. Suppose one actual input history from a fixed initial state has endpoint z and endpoint-Jacobian image V of rank r<d. Then some admissible prefix of length at most L followed by one final transition can be appended so that the resulting ONE history has endpoint-Jacobian rank at least r+1.

Proof. Since the raw prefix pullback generators span the tangent space at z, at least one raw generator g^*Y_j(z) lies outside V. Otherwise every raw generator would be in V, hence every smooth local linear combination of them would also be in V, contradicting full tangent span. Here g=f_(u_L) composed through the selected fixed admissible prefix, possibly of length zero, and

g^*Y_j(z) = (Dg(z))^(-1) Y_j(g(z)).

Append exactly that prefix to the existing history, then take one final transition at g(z) with any admissible final control. Let F denote this entire appended state map from z to the new endpoint. Its differential DF(z) is invertible as a product of nonsingular fixed-control differentials.

All old endpoint-Jacobian columns are transported to DF(z)V, so they remain independent and have rank r. Now vary the j-th coordinate of the NEW final input, leaving all earlier inputs fixed. Its endpoint derivative at the last step is partial_(u_j final) f_(u final)(g(z)). Pull this derivative back through the appended map:

(DF(z))^(-1) partial_(u_j final) f_(u final)(g(z))
= (Dg(z))^(-1) (D f_(u final)(g(z)))^(-1)
      partial_(u_j final) f_(u final)(g(z))
= g^*Y_j(z).

The final input's control-variation field is evaluated at its chosen control. In this tanh sensitivity system, Y_j is independent of that control. By construction this vector is outside V. Since DF is invertible, its image is outside DF(V). The new input derivative is therefore independent of all r transported old derivatives. The new endpoint Jacobian has rank at least r+1.

At every step, this extends the one already constructed history. It does not combine endpoint Jacobians from different histories. QED.

For the tanh sensitivity system, Section 8 gives L=3 and Section 2 verifies the nonsingular differential. All controls used in coefficient extraction and in the appended steps lie in the allowed nonempty open input set.

==================================================
10. HORIZON BOUND
==================================================

Start with the length-zero history; its endpoint derivative image has rank 0. If its current rank is r<d_n, the lemma appends a forward prefix of at most L=3 transitions, selected from the pullback generator outside the current derivative image, and one final transition whose new input coordinate produces that outside direction.

Thus each rank increment costs at most L+1=4 transitions. At most d_n increments are needed to reach rank d_n. Therefore a single history of length at most 4d_n reaches full endpoint rank. If its length is less than 4d_n, append fixed admissible inputs. Each such transition has invertible state differential, so it maps the endpoint-Jacobian image injectively and preserves its rank. Hence the fixed horizon T=4d_n suffices.

This is an existence bound. It is not the minimum input-count bound, and it does not produce a short or well-conditioned input schedule.

11. EXPLICIT ALL-WIDTH MATRIX FAMILY
==================================================

For every n>=2 choose

R = I - 11^T/(n+1),
W = I,
b = 0.

Let J=11^T, so J^2=nJ. Direct multiplication gives

(I-J/(n+1))(I+J)
= I + J - J/(n+1) - nJ/(n+1)
= I.

Therefore R^(-1)=I+11^T. Its diagonal entries are 2 and off-diagonal entries are 1, so every inverse entry is nonzero. R and W are invertible, and the theorem applies at every width n>=2. This explicit family establishes that the theorem's hypotheses are nonempty at every width; it does not narrow the theorem's universal quantifier to this family.

==================================================
12. WIDTH n -> n+1 AND SCHUR-COMPLEMENT COROLLARY
==================================================

THE MAIN ARBITRARY-WIDTH THEOREM HAS ALREADY BEEN PROVED BEFORE THIS SECTION.

The endpoint dimension increment is

d_(n+1)-d_n
= 2(n+1)^3+(n+1)^2+(n+1) - (2n^3+n^2+n)
= 6n^2 + 8n + 4.

The following argument is a consequence/check on a coupling family, not the induction step needed to prove the theorem. Put N=n+1 and beta=1/(n+2), and consider

R_epsilon = [ I_n-beta J_n       -epsilon beta 1_n ],
            [ -epsilon beta 1_n^T  1-beta       ],
W=I_N, b=0.

At epsilon=0 the old n by n block has inverse I_n+J_n/2, so it meets the sufficient hypotheses for width n. For 0<epsilon<=1, write R_epsilon=I-beta K_epsilon. The matrix K_epsilon is nonnegative and irreducible, with row sums at most N=n+1. Since beta*rho(K_epsilon)<=beta*N<1, the Neumann series for R_epsilon^(-1) converges and has strictly positive entries. Thus the width-N sufficient hypotheses hold for epsilon>0; epsilon=1 is the explicit family from Section 11.

Use common horizon H=4d_N. At epsilon=0, the old-block theorem supplies a nonzero old d_n by d_n endpoint minor as an analytic function of the input history; append fixed inputs if needed to reach H. At epsilon=1, the width-N theorem supplies a nonzero full d_N by d_N minor as an analytic function of the same input-history variables. Each nonzero set is open dense in the connected open input domain, so their intersection is nonempty. Fix one history from the intersection.

For this history, a full-width minor is analytic in epsilon and nonzero at epsilon=1, so it is not identically zero. There are therefore full-rank epsilon values arbitrarily close to zero. The selected old minor remains invertible near zero. Choose one such epsilon and extend its selected old input columns to a full input-column basis, retaining the old rows/columns. In that selected square Jacobian, block elimination gives

det J_selected(epsilon) = det J_old(epsilon) det H_new(epsilon),

where H_new is the Schur complement for the d_N-d_n new endpoint directions. The selected determinant is nonzero at the chosen epsilon; det J_old is nonzero near zero. Hence det H_new is an analytic function near zero that is not identically zero. Its Taylor expansion has a finite first nonzero coefficient. This proves existence of a nonzero leading Schur-complement coefficient for suitable histories in this family, without calculating its order or value. No explicit determinant recurrence or closed-form coefficient is established.

13. FIRST-INTEGRAL COROLLARY
==================================================

Suppose a global C^1 scalar function I on the augmented state manifold satisfies

I(f_u(z)) = I(z)

for every state z and every admissible control u. Differentiate this identity with respect to u_j:

dI_(f_u(z)) [ partial_(u_j) f_u(z) ] = 0.

Differentiate with respect to z:

dI_(f_u(z)) D_z f_u(z) = dI_z.

Combining these equations and using the nonsingularity of D_z f_u gives

dI_z [Y_j(z)]
= dI_(f_u(z)) D_z f_u(z) (D_z f_u(z))^(-1)
       partial_(u_j)f_u(z)
= dI_(f_u(z)) [partial_(u_j)f_u(z)]
= 0.

By the invariance identity at subsequent states, the same argument shows dI annihilates every forward-prefix pullback of every Y_j. Section 8's full tangent-space span then implies dI_z=0 at every state z. The augmented state manifold is R^(d_n), which is connected. A C^1 function with zero differential everywhere on this connected manifold is constant. Therefore no nonconstant global C^1 first integral exists under the theorem's hypotheses.

This is a statement about global first integrals. It does not exclude arbitrary smooth functions that are flat on a reachable open set, nor claims outside the hypotheses.

==================================================
14. ANALYTIC GENERICITY
==================================================

The logical order is:

1. The arbitrary-width existence theorem is proved first for each fixed n and every fixed admissible R,W,b and initial augmented state.
2. Therefore, at that fixed width and parameter point, at least one d_n by d_n endpoint-Jacobian minor is nonzero for some input history of horizon T=4d_n.
3. The finite unrolled tanh recurrence and its parameter sensitivities are real analytic in the parameters and input history. The selected minor is therefore a real-analytic function.
4. Since it has a nonzero value, it is not identically zero. On a connected open domain, the zero set of a nontrivial real-analytic function has empty interior and Lebesgue measure zero.
5. Thus for each fixed parameter point satisfying the sufficient hypotheses, full endpoint rank holds for generic input histories at that fixed horizon. Jointly, full-rank parameter/history pairs are generic as well. This genericity conclusion follows from existence; genericity is not used to prove existence.

The conditions R invertible, W invertible, and all cofactors corresponding to entries of R^(-1) nonzero hold on an open dense full-measure subset of the matrix parameter space: their failures are zeros of nontrivial determinant/cofactor polynomials. No conditioning lower bound or finite input-grid probability guarantee follows.

==================================================
15. WHAT THE THEOREM DOES NOT PROVE
==================================================

The theorem proves structural reachability of the full augmented coordinate dimension for the specified dense, fully actuated, fixed-parameter tanh recurrence under the stated sufficient conditions. It does not prove:

- any conditioning guarantee for the full-rank endpoint Jacobian;
- a finite-precision storage lower bound;
- a practical memory lower bound;
- that any future loss or task can observe all reachable sensitivity directions;
- that exact gradients improve learning;
- a computational lower bound or a required runtime cost;
- that every recurrent architecture has this property;
- that the result requires a new primitive or architecture.

The proof draft has exact symbolic algebra checks but is not a formal proof-assistant verification or an independent mathematical review. The sufficient horizon 4d_n is not shown to be minimal. Deep-stack arbitrary-width accessibility is not proved here.
