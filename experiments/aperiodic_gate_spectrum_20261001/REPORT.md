# Aperiodic gates: query-visible recent-history diagnostic

2026-10-01. **Numerical evidence favors quadratic aggregation for these histories;
the general arbitrary-aperiodic logarithmic gap remains unresolved.**

No new theorem, finite-radius dimension certificate, encoder, architecture or
learning experiment was attempted. The accepted theory was not modified.

## 1. Contract, chronology and measured object

The model is the accepted hard rotating/dense tanh family at **c=1**,
gamma=1/n, W=I, b=.05*1. R is the frozen finite dense perturbation and operator
rescaling of diag((1-1/n)O, I/(100n)), with the accepted Householder-conjugated
cyclic O. Every R/W/b entry remains independently differentiated. The parameter
count is P=2n^2+n. No replacement with an unrelated random dense matrix.

Unchanged epsilon=1e-3, group-RMS parameter units
wR=||R||F/n, wW=1/sqrt(n), wb=.05, head q=1/sqrt(n)*1 and
beta=max(1,||R||F). The final loss is q^T h/beta. The actual input cube is
(-.5,.5)^n. Every generated input has absolute value at most .359769605.

Primary source-map preregistration/source freeze **ff8aa58** was committed and
pushed before official measurements. Widths 16,32,64,96,128,200,256;
seeds 62101,62102,62103 for each of diffuse, random_pulse and
query_adversarial_pulse. There are 63 aperiodic cases and seven scalar controls.
Histories were generated by the frozen rules, with no outcome-dependent search.
The pulse strategies alternate zero-memory states with randomly sized coordinate
pulses; the coordinate/amplitude sequence is aperiodic and noncommuting, not a
fixed two-step gate pattern. The adversarial rule greedily maximizes a declared
query-weighted transport contrast, not the final spectral count.

The primary map intentionally follows the review's source-history suggestion:
source coordinates vary; the memory gate history is held fixed. All memory-output
R/W responses are included in its reference propagation, but fast source-output
gate derivatives and tiny dense-coupling derivatives are omitted. This is NOT

### Fixed-h chart and input scale

Prescribe h0=hT=0 and free h1,...,hH; realize
x_t=atanh(h_t)-R h_(t-1)-b, with T=H+1. Parameters differentiate the resulting
inputs held fixed. History differentiation is a separate outer operation.
The last reset compensates exactly for every history variation, so this chart
lies in the fixed-endpoint hidden-state fiber.

For the complete map, dx_t=diag(1/(1-h_t^2))dh_t-R dh_(t-1).
The resulting block-tridiagonal input Gram is Cholesky-whitened; singular values
refer to ONE unit of Euclidean total physical input-history perturbation.
The full chart has nH free coordinates. The source restriction has lH coordinates.
This scale is not a box permitting one unit in every time coordinate.

The previous input-SD convention sqrt(3/32)=.3061862178 and a .05 input-norm
radius are separately recorded. Epsilon is never altered. All radius-scaled
counts remain LOCAL linear diagnostics, not nonlinear robust dimensions.

## 2. Query-visible spectra, not raw sensitivity rank

The permitted-query distance is a supremum and is not generally a Hilbert norm.
Consequently there is no unique ordinary SVD for that norm. We measured explicit
Euclidean maps without changing the permitted queries:

1. **BOX-RMS (primary):** RMS normalized gradient response over ALL sign vertices
   of a realizable one-step future gate box g in [sech^2(.5),sech^2(.25)]^n.
   These are actual future inputs .2 or .45. For c=R^T diag(g)q/beta,
   C=E[c c^T]=R^T(s_g^2 I+g_mid^2 11^T)R/(beta^2 n).
   Apply its square-root factor to the state axis of dS before computing spectra.
   RMS is a lower diagnostic for the allowed query supremum, not equality to it.
2. **CONTINUATION-RMS:** 32 actual seeded continuations, lengths 1,2,4,8;
   actual recurrent adjoints, same normalization. A separate lower diagnostic.
3. **ALL-QUERY ENVELOPE:** (a/beta)||dS||F bounds every permitted query of the
   SAME source/memory component. It may greatly overcount visible directions;
   it is not a full-history upper bound.

For fixed h, direct parameter injections along a given future continuation are
identical for the compared endpoints and cancel in gradient differences. The
current sensitivity difference is queried by the transported adjoint.

Every spectrum is saved, including the long tail. Counts mean sigma>epsilon
at the declared unit input norm. They do NOT mean a proven continuous-memory
lower bound: finite-radius joint separation has not been established.

### Upper envelope exposes a weak mixed tail

For random pulses, envelope counts range 1,920--1,952 at n64, then
17,920--18,432 at n256. Mean count/n^2 drops from .474 to .278;
mean count/(n^2 ln n) from .1140 to .0501. For adversarial pulses these drop
from .477 to .173 and .1146 to .0312. Thus a larger, weak mixed tail exists;
it is not valid to call all those envelope directions query-visible.
The envelope's n>=64 fits favor n^2 over n^2 log n but fit poorly:
random-pulse relative RMSE 24.5% versus 33.8%, adversarial 40.4% versus 47.0%.

At n256, the unchanged input-SD scale still gives 8,192 BOX-RMS source directions,
but the .05-radius linear diagnostic gives ZERO. The latter is an important
warning: unit-norm tangent counts are not a width-uniform robust section proof.

## 8. Interpretation and single next step

**Quadratic scaling is more plausible than n^2 log n for the measured local
query-weighted maps.** Aperiodic gate variation does create extra directions,
but the broad strong source spectrum remains n^2/8 while orbit-separated history
columns are almost aligned. The full small-width map adds gate/source information
without displaying a log-enhanced trend. This favors an aggregation proof effort,
not a claim that the logarithm has been removed.

Recommended next theorem: a **uniform query-seminorm merger bound for transported
feature moments under unbounded aperiodic gates**, controlling the discarded
moment tail directly against every normalized late adjoint and counting all
recursive state. It must handle complete gate-history variations, not just the
source subspace; age-orbit correlation observed here is motivation, not an
assumption that may be imposed on arbitrary histories. General accepted bounds
remain Omega_c(n^2) <= d_rob <= O_c(n^2 log n). STOP this diagnostic stage.
