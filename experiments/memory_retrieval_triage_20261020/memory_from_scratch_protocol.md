# From-scratch memory: fixed protocol, 2026-10-20

The earlier answer-only repair did not change architecture. It changed data exposure and froze nongate weights for 128 late updates. Both new arms therefore use the SAME shared-projection learned-memory controller (11,507 parameters), initialized randomly with seeds 101,211,307. "Original" means the shared controller immediately preceding the prior gate repair, not the older untied-projection variant. No pretrained weights or correspondence labels enter either fresh run.

Original policy: 512 answer-CE updates of all weights. Repair policy: first 384 answer-CE updates of all weights; final 128 updates of gate weights only. Both reset AdamW at update384, lr .003/default weight decay .01, clip1, batch12 histories, eight queries/history. Identical seed-paired initialization and examples; no loss regularizer or extra labels. Each arm is trained separately from initialization (no checkpoint loading or shared-stage shortcut). Different trainable sets in the last stage are the deliberate intervention; equal optimizer updates/data are not equal FLOPs. If both policies are identical before freezing, their update383 states must be bit-identical.

Data: eight independent uniform binary final facts; each slot receives an initial write and a later overwrite. Initial values are independent except that if all eight equal the final values, one old value is flipped, guaranteeing a genuine overwrite without biasing final facts. Random command order within each group and random nonoverlapping positions among distractors. Body length per batch randomly48/64/80; last command ends the body, at a varying input position. Trailing idle lengths randomly0/16/64/128. Commands are ordinary tokens, with no event masks or addresses passed into the neural forward or loss. Cross entropy uses only final queried values.

Training distractors: all filler IDs22..29 and decoy VALUE IDs10/11 occur. Adjacent PURE FILLER pairs are restricted to equal parity; VALUE decoys can bridge the groups. OOD evaluation uses opposite-parity adjacent PURE FILLER pairs, absent from every training input. Same token identities; new local combinations, not new vocabulary. ID evaluation uses the training pair rule on fresh seeds. Seed spaces: training11000000000+seed*1000003+step*8191; testing21000000000+seed*100003+chunk*677. Guided reference uses test seeds101/211/307 paired with source checkpoints17/29/43. Record exact dataset hashes. No search, validation-based stopping, or final-test selection.

Evaluation: 96 histories per seed/domain/horizon, chunks32, body64, exactly256/1024/4080 guaranteed idle tokens after the last write. Identical paired bodies/final facts across horizons. Metrics all-eight recall, per-bit accuracy, per-query accuracy, valid/invalid event gate means (diagnostics only), idle gate integral, bank cosine/relative drift, body-correct retention. Causal ablation zeros bank contribution at readout, leaving GRU/query states unchanged. Late-update test:1024 idle tokens, one fact flipped, then256 idle tokens, 64 records/seed/domain. Score all facts, changed fact and unaffected facts. Reference only: prior guided answer-only repaired checkpoints, no new updates.

Primary reliability criterion: >=90% complete records in EVERY fresh seed at OOD4080 and >=95% of body-correct records retained; causal bank ablation must reduce per-bit accuracy by >=20 points in every qualifying seed. Policy advantage criterion: >=5 pooled percentage points at OOD4080 with no seed loss >5 points, same data/update budget. Report actual limited-budget failures without claiming impossibility. The two arms have no architectural difference, so no architecture-superiority claim is possible here.

Before training: reproduce prior repaired checkpoint scores and nongate tensor identity; compare generic optimized forward and ALL parameter gradients with native forward; verify dataset replay/valid masks/combinatorial holdout and independent final facts. Diagnose weak seed29 with saved weights: per-query errors, write/read soft addresses, collision-conditioned errors, and oracle-only routing/gating interventions. This is causal diagnosis, never training input.

CPU only, four intra-op threads (below six allowed), one inter-op thread, serial execution, no workers, no GPU; no budget extension after seeing results. Save trained states, per-step traces, per-record predictions/targets, source hashes and resource metrics. Preserve all existing files; reuse directory; no PR/outreach. Stop after one fixed experiment and verification.

Reference limitation: the guided checkpoints' historical generator allowed unrestricted filler pairs. The OOD bigrams are provably unseen to the two fresh arms, not necessarily unseen to the guided reference. Its exposure and training guidance differ; it is never used for a fair superiority claim. No new token identities are evaluated in this experiment.
