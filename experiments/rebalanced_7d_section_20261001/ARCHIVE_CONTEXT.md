# Read-only audit context archive

The owner-reported independent direct audit already existed in the working
tree before this experiment, but was untracked. Its files were read and hashed
in METHOD_FROZEN.json before any new numerical scores. To make those frozen
dependencies available from a Git checkout, they are now added without changing
their working bytes, under a raw-byte preservation attribute. This is packaging
of existing development context, not a new audit, rerun, mathematical review,
or retrospective preregistration. The audit remains numerical evidence and
its original claim/limitations/provenance are preserved.

No Claude notebook, accepted kernel, failed 7D certificate, or GAS-0 file is
changed. Any ignored audit log captured by the prospective source manifest is
explicitly added as evidence. Exact hashes are checked against that manifest.
