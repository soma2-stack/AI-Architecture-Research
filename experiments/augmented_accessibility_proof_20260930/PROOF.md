# Arbitrary-width accessibility of the tanh parameter-sensitivity lift

Date: 2026-09-30. This is a mathematical proof draft, supported by exact symbolic
checks. It is not a formally verified proof or an independent expert review.
The previous interval certificates remain unchanged. No new numerical endpoint
sweep, learning experiment, or architecture proposal is used here.

## 1. Statement and sufficient conditions

Let n >= 2, m=n, and differentiate all P=2n^2+n entries of theta=(R,W,b).
Keep theta fixed during each trajectory and set h0=S0=0. For an arbitrary
parameter direction delta=(deltaR,deltaW,deltab), write S delta for its state
derivative. The exact augmented map is

    q=Rh+Wu+b,  h'=tanh(q),  G=diag(sech^2(q)),
    S' delta = G [ R S delta + deltaR h + deltaW u + deltab ].

Theorem. If R and W are invertible and every entry of R^{-1} is nonzero,
then for inputs in any nonempty open subset of R^n there is a finite history
with full endpoint Jacobian rank

    d=n+nP=2n^3+n^2+n.

A sufficient horizon is T=4d. This bound is conservative; it does not establish
the counting-minimum horizon P+1. The result also holds from any fixed augmented
initial state, although the physical derivative experiment uses S0=0.

An explicit rational parameter family satisfying the conditions at every width is

    R=I-11^T/(n+1), W=I, b=0,
    A=R^{-1}=I+11^T.

Thus the full structurally allowed sensitivity dimension is attained for
arbitrary n, rather than only by independent embeddings of width-2 witnesses.

## 2. Framework, local invertibility, and parameter coordinates

For fixed u, D_z f_u is block triangular with diagonal blocks GR and its
P-column lift. Hence det(D_z f_u)=(det(GR))^(P+1) != 0 everywhere.
The map is a diffeomorphism onto (-1,1)^n x R^(nP), with inverse obtained from
h=R^{-1}(atanh(h')-Wu-b) and then the affine inverse for S.
It is NOT a global diffeomorphism of R^d onto R^d.

Jakubczyk--Sontag's discrete-time control framework motivates the control
variation and pullback notation. Their paper's default global-diffeomorphism
hypothesis must not be silently substituted here. Sections 3--8 below prove the
needed forward endpoint-rank implication directly, using only nonsingular
one-step differentials. No negative-time control trajectories are assumed.

At a chosen parameter point W0 invertible, the constant transformations
u_new=W0 u and W_new=W W0^{-1} preserve endpoint rank. W0 is held constant when
differentiating; all W_new entries remain parameter directions. We can therefore
work at W=I. Let A=R^{-1}, a_i=A e_i. All A_ij are nonzero.

For a vector field V define f_u^* V=(D_z f_u)^{-1} V(f_u(z)). Define
M_k as the local smooth module generated by all such pullbacks of control fields
along forward prefixes of length <=k. In particular f_u^* M_k is contained in
M_(k+1). A smooth coefficient evaluated at f_u(z) remains a smooth coefficient.
These are modules of fields; dimensions below are pointwise spans, NOT ranks
of a single short endpoint map. Section 8 supplies that missing implication.

### Coefficient extraction lemma

Suppose fields depending on a constant control satisfy
V(u,z)=sum_a phi_a(u,z) V_a(z). If the scalar functions phi_a(.,z0) are linearly
independent on an open control set, choose finitely many constant controls whose
evaluation matrix is invertible at z0. It stays invertible near z0. Solving this
matrix system expresses every V_a as a smooth local linear combination of the
corresponding V(u,.) fields. Therefore each coefficient field is in the same
module. This is ordinary finite-dimensional linear algebra, not a Lie-bracket
limit or a state-dependent control substitution into a fixed-control map.

## 3. Exact control variation and its first pullback

Define Y_j=(D_z f_u)^{-1} partial_(u_j) f_u. Direct differentiation gives

    Y_j = ( a_j, -A deltaR a_j + A deltaW e_j ).

The second entry specifies a linear map from parameter directions into vertical
S variations; it has no bias component. Y_j is independent of u,h,S.
It is the parameter-jet lift of the base control variation R^{-1}W e_j.

Set c_i=cosh^2(q_i), g_i=sinh(2q_i). The first pullback is

    f_u^* Y_j = sum_i c_i V_ij
                 + sum_i A_ij g_i D_i
                 + sum_(i,k) A_ij u_k g_i U_ik,

where

    U_ik = (0, a_i deltaW_ik),
    V_ij = (a_i A_ij,
             -A deltaR a_i A_ij
             -a_i (A deltaR a_j)_i
             +a_i (A deltaW e_j)_i),
    D_i = (0, a_i [deltaR h + deltab + R S delta]_i).

The D_i term retains the actual tied parameter injection. It is not an
independently assignable external source. This term is essential for bias
accessibility and distinguishes the argument from hidden-state matrix algebra.

For fixed z, the functions {c_i,g_i,u_k g_i} are linearly independent on any
nonempty open control set. Expand in exponentials exp(+/-2u_i): their distinct
frequency vectors have affine polynomial coefficients. The coefficients of u_k
force all u_k g_i coefficients to zero; the two opposite exponentials then
separate c_i from g_i. State-dependent shifts of q multiply exponential terms
by nonzero factors. The constant terms of c_i do not create a dependence.
The extraction lemma therefore puts every U_ik,V_ij,D_i in M_1.

This formula can alternatively be checked without invoking jet terminology:
for a proposed variation (v,K),

    delta h'=GRv,
    delta S'=GRK+G deltaR v
                 +diag(tanh''(q) Rv)[RS delta+deltaR h+deltaW u+deltab].

Substituting the displayed pullback gives Y_j evaluated at the next state.
Exact symbolic checks verify this identity for arbitrary directional variables.

## 4. Every W sensitivity direction lies in M_2

For any vertical field, pullback acts on its parameter columns separately:

    f_u^*(0,K)=(0,A G^{-1} K(f_u(z))).

In particular

    f_u^* U_ik = sum_l c_l (0,a_l A_li deltaW_ik).

The c_l functions are independent and A_li !=0. Extraction gives every constant
field (0,a_l deltaW_ik) in M_2. They span all n^3 W sensitivity coordinates.
No historical trajectory or derivative buffer is being discarded in this
argument; it concerns attainable degrees of freedom, not an online algorithm.

## 5. Every R sensitivity direction and every h direction lies in M_3

Remove the W vertical component from Y_j using section 4. This gives

    Z_j=(a_j,-A deltaR a_j) in M_2.

Subtract A_ij Z_i and the W component from V_ij. The result is

    H_ij=(0,-a_i (A deltaR a_j)_i) in M_2.

The n^2 scalar covectors C_ij=(A deltaR A)_ij form a basis of the R parameter
dual, because deltaR -> A deltaR A is invertible. Pulling back H_ij and
extracting its c_l coefficients gives all fields (0,a_l C_ij) in M_3.
These span all n^3 R sensitivity coordinates. Subtract the full R and W
components from Y_j to obtain (a_j,0) in M_3, spanning every hidden-state
direction. This produces independent parameter-sensitivity columns, not only
a full algebra of hidden-state propagation matrices.

## 6. Every bias sensitivity direction lies in M_3

Let S_b be the n x n bias derivative block, Q=I+R S_b. The bias projection of
D_i is (0,a_i e_i^T Q). At the next state S_b'=GQ and Q'=I+RGQ. Thus the bias
projection of its pullback is

    K_i(G)=A G^{-1} a_i e_i^T (I+RGQ).

Write gamma_l=G_ll. Expanding gives

    K_i(G)=sum_l gamma_l^{-1} a_l A_li e_i^T
            +sum_(l,k) (gamma_k/gamma_l)
                         a_l A_li R_ik e_k^T Q.

The R/W projections of f_u^*D_i can be subtracted using the complete vertical
bases already in M_3; this subtraction has smooth coefficients. Projection on
parameter columns commutes with vertical pullback. Therefore K_i is itself a
pure-bias field in M_3 for every fixed u.

The Laurent monomials gamma_l^{-1} are distinct from all gamma_k/gamma_l.
The ratios may coincide with each other (k=l gives 1); aggregate those terms.
Distinct Laurent monomials are linearly independent on any open positive box.
Inputs permit such a box of gamma values: choose q_i nonzero in an open input
box so the coordinatewise sech^2 map has nonzero differential. Consequently
extraction isolates each constant coefficient a_l A_li e_i^T. Since A_li !=0,
all n^2 pure-bias directions belong to M_3, irrespective of S_b or Q's rank.

The constant I in Q'=I+RGQ is what supplies these directions. Dropping it,
or treating S_b as a free low-rank snapshot, would lose the proof.

## 7. Full augmented span at every state, at every width

The sections above give the direct sum

    M_3(z) = horizontal h (n)
               + vertical R columns (n^3)
               + vertical W columns (n^3)
               + vertical b columns (n^2)
            = T_z R^d.

The individual a_l form a basis; the R covectors C_ij form a basis; parameter
blocks are disjoint. The span is full at EVERY augmented state, not merely
at a numerical sample. It does not require Lie brackets. Nonlinear gate
coefficient independence and the tied sensitivity injections supply the result.

## 8. From the union of variations to ONE forward history

Here is an elementary rank-increment lemma avoiding an inappropriate appeal
to global invertibility or a union of different input histories.

Suppose an existing endpoint map from a fixed initial state reaches z with
derivative image V of rank r<d. Since M_3(z)=T_z M, some raw generator
g^*Y_j(z), for a fixed forward prefix g of length <=3, lies outside V.
If all raw generators were in V, their smooth linear combinations at z would
be in V as well, contradicting full span.

Append this prefix and then one more step with any admissible control. Its
last input variation in direction j, pulled back through the whole appendage,
is exactly g^*Y_j(z). The old input derivatives pull back to V. The appended
state differential is invertible, so the new endpoint derivative has rank at
least r+1. This is one actual extension of the existing history, not a linear
combination of different histories.

Starting from rank zero, iterate at most d times. Each extension adds at most
four steps, so a history of length <=4d has full endpoint rank. Appending fixed
inputs preserves rank, giving T=4d. The submersion theorem yields a locally
open set in the augmented endpoint space. This proves the stated theorem.

## 9. Genericity and rational witness existence

The explicit family supplies a full-rank point for every n with T=4d.
Some maximal minor is nonzero there. Its determinant is real analytic in theta
and the input history, so it is not identically zero. On the connected full
real parameter-input domain, its zero set has measure zero and empty interior.
At the explicit parameter slice, the same assertion holds for input histories.
Thus fixed-width genericity is justified separately at EVERY width by the
all-width argument, not transferred from the n=2 certificate.

The sufficient R/W conditions themselves hold on an open dense full-measure
parameter set (excluded determinants/cofactors are nontrivial polynomials).
This is a stronger qualitative accessibility statement, not a conditioning
bound or a probability estimate on a finite input grid.

With the rational parameter family, a full-rank open input neighborhood contains
rational inputs. Exhaustive enumeration plus sufficiently precise interval
minor checking would eventually find a certificate, but is unnecessary here
and was NOT run. The proof does not specify a short, well-conditioned pulse
schedule, an explicit determinant value, or a minimal-horizon construction.

## 10. Width induction and the leading Schur coefficient

The theorem bypasses the earlier unproved induction. It also gives an existence
answer for a specified coupling family. Set N=n+1 and beta=1/(n+2):

    R_epsilon = [[I_n-beta J_n, -epsilon beta 1_n],
                 [-epsilon beta 1_n^T, 1-beta]], W=I_N, b=0.

At epsilon=0 the old block has inverse I_n+J_n/2 and therefore satisfies the
theorem at width n. For 0<epsilon<=1, write R=I-beta K. K is nonnegative,
irreducible, and has row sums <=N; beta rho(K)<1. The convergent Neumann series
has strictly positive entries, so every inverse entry is nonzero. The theorem
applies at width N. Epsilon=1 is precisely the explicit all-width family.

Use common horizon H=4d_N. An old d_n endpoint minor is nontrivial as an analytic
function of the input history at epsilon=0 (append steps if necessary). A full
d_N minor is nontrivial at epsilon=1. Their nonzero input sets are open dense;
choose one history in their intersection. It can be chosen rational.

For this fixed history, the latter determinant is analytic in epsilon and is
not identically zero. Full rank therefore occurs for some epsilon arbitrarily
near zero. The selected old minor stays invertible nearby. At one such epsilon,
extend its input columns to a full column basis; keep that selection fixed.
Ordering the old output/input coordinates first gives

    det J_selected(epsilon) = det J_old(epsilon) det H_new(epsilon).

The Schur determinant is analytic near zero and not identically zero. Hence its
Taylor series has a finite-order NONZERO leading coefficient. The number of
additional directions is d_(n+1)-d_n=6n^2+8n+4, exactly as before.

This proves existence/generic nonvanishing for suitable inputs in this family,
NOT nonvanishing for every previously fixed witness, every preselected minor,
or the shortest counting horizon. No formula for the leading order/coefficient,
determinant factorization, or recursive determinant value was found. Such a
formula is no longer required for the full-dimensional existence theorem.

## 11. Invariant attack and controls

If a global C^1 first integral satisfies I(f_u(z))=I(z) for every z,u,
differentiation in input and state shows that dI annihilates Y_j and every
forward-prefix pullback of Y_j. Section 7 then implies dI=0 everywhere; I is
constant on the connected augmented state manifold. Thus there is no nonconstant
global C^1 first integral under the stated sufficient assumptions.

Likewise, a real analytic or polynomial identity holding for every reachable
endpoint from h0=S0=0 must vanish identically, since the endpoint set contains
an open set. No claim is made about arbitrary smooth functions that are flat on
that open set, exceptional singular parameter slices, or nonlocal encodings.

Independent recurrence remains an explicit obstruction/control: each parameter
has one recurrent output owner; sensitivities in every other state row are
identically zero. P_ind=n^2+2n, endpoint dimension n^2+3n. Here A is diagonal,
and the nonzero inverse-entry hypothesis deliberately fails. Full rank within
this smaller space does not contradict the theorem for dense interaction.

Shared-linear control also remains restricted. For R=gamma I and h0=S0=0,
S_b(t)=sum_(k=0)^(t-1) gamma^k I. Off-diagonal bias sensitivities vanish and
the diagonals agree. On a domain excluding S_b,22=1/(1-gamma), the rational
first integral (S_b,11-a)/(S_b,22-a), a=1/(1-gamma), is preserved. The fixed-T
endpoint input rank is <=2n for this shared-linear control. For generic linear
R, the earlier characteristic-polynomial argument bounds input rank by 2n^2.
Identity activation makes c_i constant and g_i zero; the nonlinear coefficient
extraction does not apply. The proof therefore does NOT falsely label a dense
linear sensitivity snapshot as full-dimensional.

## 12. Scope, verification, and sources

Proved here: an arbitrary-width, fully actuated, fixed-parameter dense tanh
sensitivity lift has a full-dimensional locally reachable endpoint under stated
generic sufficient conditions. Its independent coordinate count is Theta(nP).
Not proved: future losses observe all coordinates, finite-precision storage
requires nP words, exact gradients help learning, every recurrence has this
property, or a new architecture is necessary. This is not an observability or
learning experiment. No deep-stack arbitrary-width theorem is claimed here.

Exact symbolic checks at n=2,3 cover the two control-field identities, coupled
injection formula, R covector extraction, coefficient independence, vertical
pullback, bias Laurent expansion, parameter family, width-extension endpoints,
dimension difference, and linear first integral. They do not mechanize the
analytic lemmas or independently peer-review the whole proof. An external
mathematical verification remains the single next recommended step.
