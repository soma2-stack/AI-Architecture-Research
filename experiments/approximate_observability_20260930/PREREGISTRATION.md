# Quantitative / approximate observability

The accepted accessibility and exact continuous-state results are premises.
They are neither modified nor rerun. This stage derives finite-error statements
and checks conditioning at already certified witnesses, without training.

Frozen numerical choices are in config.json. All results retain raw coordinates
as primary. Normalization uses input variance and parameter-block RMS units,
not singular-vector-dependent rescaling. Threshold tables are conditional
diagnostics; no error tolerance has been declared scientifically meaningful.

Use one CPU worker, single-threaded BLAS, no CUDA/model server, at most 3,600
measured CPU seconds including checks. Preserve all earlier artifacts and hash
every source certificate/code file used. Freeze this setup before spectra.

The principal finite-memory collision argument requires separation greater
than twice the allowed uniform absolute error. Real coordinates, finite bits,
and discrete memory states will be reported separately. A conservative explicit
reachable patch is sufficient for a conditional theorem, but its small radius
does not prove that a larger reachable patch fails to exist.

The numerical endpoint derivative is projected to the fixed-hidden-state
history tangent before counting sensitivity directions. Singular values are
reported in full at high precision; raw full-endpoint singular values are
retained for comparison. No inference about arbitrary width is made from
widths 2, 3 and 4. Finite nonlinear perturbations require a separate remainder
bound and are not automatically justified by tangent spectra.

Stop after the report. No learning, GAS-0 operation, observability scale-up,
Stage C, AMS v10 or architecture invention.
