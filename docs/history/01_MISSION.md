# AI Architecture Research Mission

## Goal

Explore and invent genuinely new AI architectures or model classes that could become broadly useful.

The objective is **not** to force a fake breakthrough or simply rename existing ideas. The objective is to search widely, question assumptions in modern AI, generate many distinct possibilities, eliminate weak ideas, and develop the strongest surviving concepts into testable research proposals.

## What Counts as Success

A strong proposal should do more than modify an existing model slightly.

It should introduce a meaningful difference in at least one of these areas:

- what the model predicts
- how information is represented
- how computation is organized
- how learning happens
- how memory works
- how reasoning happens
- how the model changes over time
- how the model interacts with an environment
- how training and inference relate to each other
- what the basic computational unit is

The architecture should also have a clear reason to exist. Being unusual is not enough.

## Do Not Assume the Answer Is

Do not begin by assuming the architecture must be:

- an LLM
- a Transformer
- Mixture-of-Experts
- a classifier
- a diffusion model
- a state-space model
- an agent framework
- a retrieval system
- a multimodel pipeline

Existing ideas can be used as components when necessary, but they should not be the entire novelty.

## Avoid Weak Novelty

Do not present any of the following as a fundamentally new architecture by themselves:

- an LLM with more memory
- RAG plus an LLM
- a new prompt format
- a larger context window
- another MoE routing method
- several agents talking to one another
- a Transformer with a small attention modification
- a different training dataset
- tool use added to an LLM
- multiple existing models connected together and given a new name

## Areas Worth Exploring

Explore broadly. Possible areas include:

- reasoning
- coding
- scientific discovery
- robotics
- simulation
- game creation
- multimodal intelligence
- continual learning
- memory
- planning
- real-time interaction
- efficient computation
- learning from limited data
- adaptation to changing environments
- autonomous skill acquisition

Do not limit the search to these areas.

## Research Attitude

Be skeptical of every idea, including your own.

A proposal is allowed to fail.

A useful negative result is better than pretending an existing idea is new.

Continue searching even after finding one promising direction.
