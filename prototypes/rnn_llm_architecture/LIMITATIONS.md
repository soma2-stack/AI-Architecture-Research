## Outstanding mathematical obligations

1. A jointly admissible continuous whole-ball section with a common exact
   endpoint, uniform **all-boundary** legal-query separation exceeding
   `.002`, linear robust dimension, and strict little-o coordinate-time
   cost. Axis tests, Jacobian singular values, rank and exact visibility
   cannot replace this obligation.
2. A diverging jointly protected control family without proportional write
   duration, or an appropriately scoped finite-error compression obstruction.
   The bounded-stage donor-family theorem does not decide the unrestricted
   problem.
3. Robust analysis of the retained un-cleared Route-7A donor feedback
   matrix. Trace-neutral scheduling is operational algebra; a new robust
   gain mechanism is **NOT IMPLEMENTED / OPEN**.
4. A consistent Route-6 survivor reader, complete chronological mass
   accounting, parameter-complement code and reference/dense error allocation
   in one legal-query contract. Separate supplied checkpoints do not make
   arbitrary trained recurrence obey the same hypotheses.
5. A complete dense realization supplied by the mathematical model if an
   actual-model guarantee is required. Reference fixtures use R0. Floating
   point checks of tiny perturbation bounds include representational error
   and cannot certify exact asymptotic dense estimates.
6. An exact arbitrary-token transition preserving donor/survivor, source,
   chronological and query assumptions. This is **NOT IMPLEMENTED**.
   A learned adapter would be theory-inspired unless those invariants are
   established. The original selected sensitivity kernel remains available.
7. Certified legal-query supremum and topological lower-section machinery.
   The implemented finite oracle evaluates supplied legal futures. It does
   not certify a supremum over all futures or a robust-D lower bound.

## Engineering and empirical limits

The new implementation has independent matrix/derivative cross-checks and
adversarial self-criticism, but no new external architecture review. The
cited independent reviews concern the existing mathematical records.

* **NOT YET TESTED:** any optimization, learned gate selectivity, language
  modeling quality, delayed recall under learned distractors, token-level
  memory capacity, trained gradient stability, inference intelligence,
  accuracy, generalization, energy-to-quality gain or architecture superiority.
* Equal width means unequal trainable parameter counts and recurrent MACs.
  Fixed recurrent buffers occupy real storage and multiply time; freezing
  them does not make computation free. A learned standard/gated baseline
  must remain strong and independently budget-matched in the next phase.
* Candidate LayerNorm/head derivatives are separate from a near-critical
  cell's norm bound. No contractivity theorem for the complete token model
  follows from its frozen recurrent spectrum.
* Protected coefficient writes can be externally closed, but input-only
  learned gates cannot inherently condition on memory content. Fast/slow
  proposal interaction can couple open channels, saturate writes, and lose
  learned retrieval. Projected state is not coordinate-wise tanh-bounded.
* Walsh orthogonality prevents linear readout cross-talk; sum-free labels
  remove a particular pair-product alias, not cubic and higher-order
  nonlinear aliases. Tests explicitly exhibit a triple-product alias.
  Any orthonormal bank preserves the closed-channel projection invariant.
* Float64 is a small-reference audit tool, not a finite-precision proof.
  Endpoint and trace equality in tests are numerical tolerances; large
  saturated fronts and long histories require their own error certification.
* Small-width chronology is validated algebraically. The reported
  `n=2048,m=8,T=44` fixture fails the asymptotic lift premises, has only
  four finite clear steps and a tiny `.002`-subthreshold supplied-query
  signal. It cannot establish robust dimension or asymptotic onset.
* The explicit fixed-source full matrix has quadratic sensitivity storage.
  Full independent parameter sensitivity can be cubic. No causal compressed
  credit encoder or finite-bit/VRAM separation has been built.
* MAC/payload estimates omit autograd tapes, temporary sequence projections,
  allocator overhead and wall-clock memory traffic. No GPU, process peak-RSS,
  training performance or hardware scaling measurements were made.

The GRU and LSTM additions are deliberately standard comparison models, not
new theoretical mechanisms. They use PyTorch `GRUCell` / `LSTMCell` in an
explicit token-by-token wrapper to preserve resets and caller-managed
streaming at arbitrary per-example token positions. This favors transparent
state semantics over fused whole-sequence kernel throughput; no speed
comparison against `nn.GRU` / `nn.LSTM` sequence kernels was made, and the
reported timings are local untrained CPU measurements.
LSTM state doubles persistent recurrent-state tensor storage relative to GRU
at the same width and depth. Equal-width models differ substantially in
parameter and MAC budgets. Parameter-matched variants change width and/or
depth, so they also change embedding capacity and path length; none is an
exact experimental control. Their language quality, learned memory retention,
trained numerical stability and superiority are all **NOT YET TESTED**.

The next inexpensive work should target a precise failed or open claim:
test a no-clear normalized joint signal or collision before adding new
architecture machinery; separately authorize tiny learned recall/token
comparisons before allocating substantial training resources.
